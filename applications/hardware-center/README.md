# AION Hardware Center

Part of the AION desktop suite (KDE Plasma / Wayland, dark-first
design system, blue/cyan accents). Implementation begins at its
milestone per documentation/milestones.md. This crate will be a
Kirigami/QML application speaking the versioned aion-api; it must
never assume particular hardware and must consume the runtime
compatibility matrix rather than hardcoding claims.
